One other thing to notice

This line:

CLI->>Config: Import settings & resolve defaults

is slightly misleading if configuration is resolved during module import rather than through an explicit runtime call. That's an implementation detail worth checking in the actual config.py.

Likewise, this:

CLI->>Logging: setup_logging(args.log_level)

is conceptually correct and useful because logging setup is an actual runtime action.
